# SAC 参数、状态与训练审核：恢复原利润目标

审查日期：2026-10-18。本报告按用户最新确认的范围组织结论，替代前一轮以平滑、峰值奖励选优的建议。此前以中心化、平方偏差和峰值奖励为基础的优化建议已撤回；相应旧实验仅保留为历史记录，不作为本轮候选。

## 1. 本轮目标与允许改动的范围

用户希望策略在原有经济机制下自然学出：零售价总体上随批发价呈低低、高高的趋势，并体现整体分时电价形态；储能在低价时充电、高价时放电；价格需求响应使低负荷时段适度增加、高负荷时段适度减少。这里要求的是总体趋势，不是每小时严格单调，也不是由代码预先指定动作。

本轮允许调整响应方程的参数、训练超参数、状态空间，以及新能源和储能参数；不改响应公式，不增加削峰奖励、额外调度约束或价格跟随规则。当前 [Task](../../sac/task.py) 唯一环境奖励为：

```text
learning_reward = original_profit × reward_scale
```

其中 `original_profit` 仍是零售收入减购电费用和储能吞吐费用。无参考收益扣减、平滑成本、峰值成本或零售价跟随奖惩。`reference_profit` 只供评价比较，不参与训练奖励；底层共享环境原有的第二路储能混合奖励也不作为普通 SAC 的训练信号。

正的固定缩放保持纯利润目标的策略排序不变，但会改变数值尺度及其与 SAC 熵项的相对量级，因此不同 `reward_scale` 的有限步学习结果不必相同。本轮把它作为训练超参数检验，不将某个缩放值解释为新增业务目标。参数入口及校验见 [Config](../../sac/config.py)和[允许覆盖的环境参数](../../sac/parameters.py)。

## 2. 单位约定：统一计算口径，保留来源不确定性

用户已授权自行作合理建模假设。本轮统一采用以下解释，**保持原始数字不变，不对已有输入实施倍数换算**：

| 量 | 本轮建模单位 | 说明 |
|---|---|---|
| 零售价、批发购电价 | 澳分/kWh，即 AUD cents/kWh | 两者必须使用同一单位后才能计算利润 |
| 负荷、风电、储能充放功率 | kW | 每步为 1 小时 |
| SOC 能量、充放电量 | kWh | 程序中的 `soc` 是能量；观测中的 SOC 才归一化 |
| 原始利润与吞吐费用 | 澳分 | 若展示为 AUD，应在报表中除以 100，并标明转换 |
| `c_es=0.5` | 澳分/kWh 吞吐 | 对充电和放电两侧分别计费 |

这是一套获授权的统一解释，**不是已经证实的原始数据单位或澳大利亚数据来源**。已核查的原 XLSX 表头没有单位，尚未确定地区、年份、数据提供者或 AEMO 下载记录。不能仅凭 `wholesale price` 列名就断言它是 AEMO 原始行情。

AER 的账单说明使用 `c/kWh` 表示零售用电单价，可作为本轮零售单位的参照。[AER：Understanding your energy bill](https://www.aer.gov.au/consumers/understanding-energy/understanding-your-energy-bill)。AEMO 的公开市场报告以 `AUD/MWh` 报告批发价格；两种单位的换算为 **1 AUD/MWh = 0.1 澳分/kWh**。[AEMO：Rising renewable energy output offsets demand growth](https://www.aemo.com.au/Newsroom/Media-Release/Rising-renewable-energy-output-offsets-demand-growth)。

因此，若以后取得明确以 AUD/MWh 标注的批发原始数据，应先乘 0.1 再导入本轮单位体系；当前不能据此把已有批发价再缩小十倍。按本轮假设，原名义批发价约 17.16–23.41 澳分/kWh，相当于 171.6–234.1 AUD/MWh；该等价换算不证明其历史来源或代表性。

## 3. 两个价格锚点有不同作用，不能直接对齐

[响应函数](../../eqnsac/environment.py)中有两条价格序列：

| 输入 | 当前范围 | 在公式中的作用 |
|---|---|---|
| `hourly_demand_reference` | 28.3–30.6 | 理性需求的响应零点；忽略需求噪声时，低于它增加需求，高于它减少需求 |
| `profile.retail_price` | 26.5 / 28.5 / 32.5 | 账单基准及相对价格变化，影响满意度与参与比例；同时用于固定参考策略 |

两者不同意味着“按原 TOU 定价”也会触发需求响应。这不是自动成立的代码错误。名义曲线、固定风电及 256 个响应随机实现下，按原 TOU 定价，谷价段平均需求变化约 **+17.13%**，峰价段约 **−17.31%**；可见原参数并不是零响应或很弱响应的基准。

若直接把需求 reference 改成 TOU，会失去原先的双向价格空间：谷时 reference 等于价格下界 26.5，不能再通过降价产生确定性的增量；峰时 reference 等于价格上界 32.5，也不能再通过提价产生确定性的削减。随机需求噪声仍可能带来小幅正负实现，但这与价格主动引导不同。因此本轮不采用这种“对齐修复”，也不逐小时倒推 reference 来制造想要的策略曲线。reference 偏移和幅度扫描仅用于敏感性诊断，实际训练仍保留原 reference 与原 TOU。

当前模型没有延期队列、未来补回或日能量守恒。单小时涨价会减少该小时需求，并不会自动把这部分需求搬到以后。报告应称为价格引起的当期需求增减；用电量下降不能全部算成跨时移峰。

## 4. 原参数已有整体价格趋势，主要矛盾是响应幅度与经济激励

### 4.1 原利润目标能够产生总体趋势

诊断将每小时零售价在 26.5–32.5 之间取 121 个点，对同一组响应随机数先计算期望利润，再选择该小时收益最高的价格。储能停机；名义负荷与批发曲线固定，风电取固定参照。这是响应模型的经济可达性检查，不是已经训练完成的 SAC，也不把事后知道单次噪声的价格当成可执行策略。

原曲率均值 `κ=0.001` 下，名义场景的最优零售价与批发价 Pearson 相关系数约 **0.936**，原 TOU 谷/平/峰时段的最优均价约 **28.38 / 30.99 / 32.50**。在另一套 27 种三源档位组合、每组合 64 个响应实现的诊断中，相关系数的案例均值约 **0.769**，相应均价为 **28.43 / 30.86 / 31.73**。因此总体低低、高高和分时形态在原模型中具有经济基础，无需写入动作规则。

首轮 500 回合策略尚未充分呈现这一可达模式，说明需要继续检验训练预算、状态表达和数值尺度；不能据此认定原模型完全无法产生趋势，也不能保证单纯延长训练必然收敛。无储能逐小时网格诊断与有储能、带熵训练的联合策略不是同一个最优控制问题，不能把前者直接当成 SAC 必须逐点复制的答案。

名义 TOU 与批发价确有少量逐时排序不一致，例如第 12 小时批发价 21.701、TOU 为 28.5，第 13 小时批发价略降至 21.640、TOU 却升至 32.5；第 23 小时属于 TOU 谷段，但基荷约 3605 kW，并非全天深谷。这些现象只说明不能同时要求每个小时严格遵循两种排序，不否定用户要求的总体趋势。

### 4.2 原曲率产生的实际弹性较强

忽略需求噪声、在三类用户共享价格时，理性总需求近似满足：

```text
D_rational = D0 − (p − p_reference)/(2κ)
```

其绝对需求斜率约为 `−1/(2κ)`。原 `κ=0.001` 给出约 −500 kW/(澳分/kWh)，随后还要经过满意度、温度、价格因素和参与比例，不能把理性层弹性直接当成最终响应弹性。

本次直接调用实际 `Environment.response()`，对 128 条响应随机流恢复相同 RNG 状态，在每个价格锚点做 ±0.01 的有限差分；边界采用单侧差分。按 `ε = (dD/dp)×p/D` 计算，得到：

| 曲率均值 κ | reference 附近各小时平均实际自弹性范围 | 名义期望利润最优价的表现 |
|---|---|---|
| 0.001 | −3.766 至 −1.845 | 有明显日内变化，8/24 小时处于上界 |
| 0.005 | −0.753 至 −0.370 | 24/24 小时处于上界 |
| 0.010 | −0.377 至 −0.185 | 24/24 小时处于上界 |
| 0.015 | −0.251 至 −0.124 | 24/24 小时处于上界 |
| 0.020 | −0.188 至 −0.093 | 24/24 小时处于上界 |

原参数在 TOU 账单价附近的实际弹性仍约为 −2.795 至 −1.436。这里的范围是各小时的样本平均，不是所有客户、所有噪声实现的置信区间。

Asadinejad 与 Tomsovic 的 WECC 案例在 p.220 Table 2 采用自身弹性 −0.1、交叉弹性 +0.07，可作为弱响应的一个文献对照点；它不是所有电力用户的通用标准。[Electric Power Systems Research 144 (2017), 215–223，DOI 10.1016/j.epsr.2016.12.012](https://doi.org/10.1016/j.epsr.2016.12.012)。该文 p.218 式(3b)显式包含跨时段弹性，不能将其交叉项当作当前无回补模型已经具有的性质。本次 −0.2 仅为额外敏感性参照，不声称该论文给出了统一的 −0.1 至 −0.2 区间。

原参数相对“微弱需求变化”的目标偏激，但仅凭一篇论文也不能宣布其在所有研究任务下错误。若要称为真实用户参数，需要实测需求与价格资料；追求好看的价格趋势不能替代弹性校准。

### 4.3 弱弹性与自主价差存在经济冲突

固定当前风电和储能动作、处于正购电区间时，单小时利润对零售价的导数为：

```text
dProfit/dp = D + (p − c)D′ = D[1 + ε(1 − c/p)]
```

其中 `c` 是批发价。对当前正批发价以及接近 −0.1/−0.2 的弱负弹性，利润通常仍随零售价上升；若无需购电，导数为 `D(1+ε)`，弱负弹性也不会自动产生内部最优价。因此价格贴上界可能是当前商业模型的理性结果，不能仅以此判断 SAC 代码有错。

在 `κ=0.02` 的扫描中，全小时、全价格网格的实际期望需求弹性约为 −0.253 至 −0.086；每提高 0.05 澳分/kWh，期望小时利润至少仍增加约 88.31 澳分，全天最优零售价均为 32.5。最低负荷四分位小时的平均需求反而减少约 2.64%，最高四分位减少约 0.87%。这说明“将需求校准为弱弹性”和“让利润策略自发选择明显谷价并增加谷负荷”是两个需要分别验证的目标。

本次共扫描 59 组曲率及 reference 偏移/幅度参数。以仅供诊断的“低负荷四分位均增 0–5%、高负荷四分位均减 0–5%”为例，没有组合同时满足；这不是用户已指定的阈值，也不是新增训练约束，更不是有限扫描能够证明的全局不可能性。

小幅调整 `κ=0.0011` 将名义最低负荷四分位的平均增量从约 5.24% 降至 2.16%，但最高四分位的平均削减仍约 15.27%。本轮将其作为保留原合成环境特征的敏感性候选，标准差同步由 `8.28e-5` 改为 `9.108e-5`，保持原变异系数；它不是已经完成实测标定的参数。实际训练没有移植诊断中的 reference 偏移方案。

## 5. 新能源 20%：定义清楚的中心情景，不是最优比例

[三源生成器](../../eqnsac/scenarios.py)按以下关系设置风机装机：

```text
wind_capacity = target_penetration × mean(nominal_load) / mean_capacity_factor
```

各风电扰动档位分别求解风速分布尺度，使期望容量因子相同。因此当前 20% 的含义是 **期望每日可用风电量 / 名义日负荷电量**。它不是每个抽样日都恰好 20%，也不是风机装机/峰负荷、某小时风电比例、扣除弃风后的实际消纳比例或经过年度气象资料验证的年新能源占比。`E[风电/负荷]` 与 `E[风电]/E[负荷]` 也不能混用。

原名义日负荷约 86,791.99 kWh，期望日风电约 17,358.40 kWh，风机装机约 1840.12 kW，相对 4838.85 kW 的峰负荷为 38.03%。每档 3000 个合成日的抽样检查中，风电与负荷平均能量之比约为 20.16%–20.34%，与生成器中心设定接近；各日波动很大，这项检查并不是年度实测验证。

20%的电量份额有直接期刊情景先例：Elliston、Riesz与MacGill（2016）在澳洲NEM全年模拟中按0–100%、10%步长设置最低可再生供电电量份额，明确包含20%（刊p.130 §3.1；p.138 Tables B.11–B.12）。该文是年度、多种可再生能源组合，不能等同本项目日尺度纯风电，也不能证明当前输入是澳洲实测数据或20%具有普适最优性。[Renewable Energy 95, 127–139，DOI 10.1016/j.renene.2016.03.080](https://doi.org/10.1016/j.renene.2016.03.080)，[正式刊版全文](https://arena.gov.au/assets/2017/06/Elliston_etal_2016_6.pdf)。核对记录见[渗透率补充证据](../../experiments/sac_parameter_revision_20261018/literature/renewable_share_supplement.json)。

20% 可以保留为定义明确的中心情景。10%/20%/30% 若用于后续对照，应标为本项目提出的敏感性网格，而非文献证明的最优区间。Ding 等讨论的 10%–30% 是其青海情景中的**储能功率/风光装机功率**，不能借来证明本项目 20% 风电能量比例合理或最优。[iScience 26(7), 106967 (2023)，DOI 10.1016/j.isci.2023.106967](https://doi.org/10.1016/j.isci.2023.106967)，定位为 Figure 2 后的 Results 讨论及 Discussion。

## 6. 储能：原规模较强，新方案用于工程敏感性

不能仅凭“几小时电池”判断整体规模合理，还要比较功率与系统负荷。原 BESS 最大充放功率约为峰负荷的 **74.74%**、风机装机的 **196.53%**；可用能量约为期望日风电的 50%。它是相对于该系统较强的日内调节资源，会显著改变购电曲线与探索难度；这不代表物理上非法，但没有现场设备或优化规划证据支持它就是合适规模。

本轮增加较小功率方案：最大功率取名义峰负荷的 20%，SOC 使用额定能量的 10%–90%，可用能量按 4 小时功率配置。具体为：

| 项目 | 原参数 | 本轮 `storage20` 候选 |
|---|---:|---:|
| 最大充/放功率 | 3616.33 kW | 967.77 kW |
| 功率/名义峰负荷 | 74.74% | 20.00% |
| SOC 下界 | 482.18 kWh | 483.89 kWh |
| SOC 上界 | 9161.38 kWh | 4354.97 kWh |
| 可用能量 | 8679.20 kWh | 3871.08 kWh |
| 可用能量/额定功率 | 2.40 h | 4.00 h |
| 考虑 95% 放电效率的满功率输出时长 | 2.28 h | 3.80 h |

新候选隐含额定能量约 4838.85 kWh，额定能量/功率为 **5 小时**，所以不能将它误写成额定 4 小时电池。“4 小时”明确指 10%–90% 区间的可用能量/功率。这个 20% 指功率/峰负荷，也不是上述文献中的功率/风光装机比例。新值由本次工程敏感性测试提出，不是复制论文的原始设备参数，更不构成工程最优证明。候选配置见 [storage20](../../configs/sac/studies/parameter_revision_20261018/storage20_scale4_500.json)及[响应参数与储能的500回合敏感性试验](../../configs/sac/studies/parameter_revision_20261018/response11_storage20_scale4_500.json)。

仍沿用原 SOC 可行区间、功率和效率的执行公式，只改变已有设备参数；没有增加额外调度约束或按时刻强制充放电。初始 SOC 继续位于下界，因此没有免费可用电量。日末仍无残值、无跨日继承；剩余能量的未来价值在当前单日任务中为零，不能将其结果直接外推为长期连续运营。

### 效率与成本

原充、放效率各为 95%，往返效率为 **90.25%**，不是 95%。Wei 等在 Appendix B 使用分别 95% 的效率，可以支持其作为已有期刊案例假设；该文 SOC 区间为 20%–80%，并不能据此宣称本项目 10%–90% 来自同一论文。[IET Energy Systems Integration 4(2), 281–295 (2022)，DOI 10.1049/esi2.12060](https://doi.org/10.1049/esi2.12060)。Ding 等补充材料 Table S5 使用 90% 往返效率，也与本项目量级接近，但其 SOC、损耗和规划问题不同，未照搬。

原 `c_es=0.5` 按 `c_es×(charge+discharge)×dt` 对两侧吞吐计费。按本轮单位假设，一个完整循环每输出 1 kWh 的费用约为：

```text
0.005 × [1 + 1/(0.95×0.95)] = 0.01054 AUD/kWh
```

这是约 1.054 澳分/kWh 输出的弱吞吐成本假设。没有电池采购价、寿命和衰减数据证明该精确值合理；它也不含完整资本回收。不能将其与 Wei 等的元/kWh 容量资本成本、年维护费用直接比较。

在充放电都能替代电网购电、忽略其他边界的条件下，每输出 1 kWh 的套利净值约为 `c_high − c_low/0.9025 − 1.054` 澳分。原名义最低/最高批发价约 17.16/23.41，给出正的套利空间，说明低价充、高价放在原利润目标下有经济基础；实际策略还受 SOC、风电、需求、剩余时间和有限训练影响，不需要额外加入“低充高放”的动作规则。

## 7. 状态与训练超参数：提供信息，不规定动作

原 full19 中有些信息可从已知时刻或当前负荷派生，上一价格/响应也不参与当前响应方程。删除冗余本身不保证更快收敛；不同维数还会改变网络初始化与参数数量。本轮使用 `market14` 作为另一种允许的状态表达：当前批发价、总负荷、风电、SOC、剩余时间、小时的正余弦表示、已知名义 TOU，以及三阶批发价和风电历史。

批发价按名义曲线均值和标准差缩放，风电按装机容量缩放。名义 TOU 是在决策前已知的信息；把它放入观测，既不是未来随机实现泄露，也不意味着 Actor 必须输出该价格。Actor 仍自主输出原二维连续动作，执行时只进行既有价格边界映射和 SOC 可行映射。

`market18` 在上述14维状态上加入未来1/3/6小时的已知名义批发价和当前响应参考价；临近日末使用最后一个名义小时。它们是公开模板信息，不是未来随机实现，不直接决定动作。四种状态都通过24小时逐时扰动未来实际数据的因果性检查。

响应参数、储能规模、观测和训练超参数影响不同环节，必须分别报告有效配置，不能把联合候选的结果全部归因于某一项。应同时检查零售价与批发价总体关系、各 TOU 时段的价格分布、充放电加权购电价、用户响应幅度、SOC 和日末余电，而不仅看累计奖励或一张平滑曲线。用户负荷与电网购电也须分开：储能可以抬高谷时购电，但不能据此宣称谷时用户消费增加。

## 8. 完成的训练与最终复核：候选尚未全面达标

本轮实际完成 **16 次训练，共 23,000 episode、552,000 个环境步**：6 次500回合敏感性试验、10次2000回合试验（包括原基线、最终候选及两个额外训练seed）。这不是单个模型训练23000回合。500回合已实际运行并保存；为检查训练预算影响，还读取两组2000回合运行中保存的500回合检查点。

训练均为纯 SAC、CPU单线程；场景采用三源随机过程，每一源 low/medium/high 抽样概率为0.2/0.6/0.2。开发验证固定27种档位组合（seed从910000000起），用于筛选观测、数值尺度和储能参数。最终候选在查看新评价前记录于[选择记录](../../experiments/sac_parameter_revision_20261018/final_selection.json)，之后固定参数，仅增加训练seed7、123的复验；最终评价是27种组合各4个新实现，共108场景，seed从950000000起。**该评价是均匀压力场景均值，不是训练概率加权的年度或真实经营预期收益。** 最终评价后没有继续据此调参或挑选其他检查点。

原基线保持full19、原响应和原储能。候选使用market18、`storage20`设备参数，响应曲率仍为0.001、新能源仍为20%；SAC学习率均3e-4、batch128、warmup1000、reward_scale0.001、gamma1、tau0.005、自动温度初值0.2、目标熵−2。响应曲率0.0011的500回合试验和更小的风电配储比例试验仅作为敏感性记录，未被冒充为最终改进。

### 相同场景与训练预算下的结果

货币列按本轮单位假设除以100，单位为 **AUD/日**；它是合成环境数值换算，不能当作已验证的澳洲实际收益。峰值是每个场景的日最大购电功率再平均，不能以平均曲线的最大值替代。价格相关系数是每场景24小时Pearson再跨场景平均；充、放电价格先在每个场景内用实际电量加权，再对有效场景取均值，不是把所有电量混合加权。

| 方案 / 训练seed | 已训练回合 | 日利润 | 储能边际收益 | 平均购电峰值 kW | 零售价–批发价相关 | TOU谷/平/峰均价有序的场景 |
|---|---:|---:|---:|---:|---:|---:|
| 原基线 / 42 | 500 | 11,111.72 | −14.99 | 3927.69 | 0.475 | 99.1% |
| market18候选 / 42 | 500 | 11,120.08 | +31.99 | 4085.94 | 0.522 | 80.6% |
| 原基线 / 42 | 2000 | 11,151.84 | −22.06 | 4105.03 | 0.557 | 100.0% |
| market18候选 / 42 | 2000 | 11,144.34 | +26.36 | 4417.18 | 0.566 | 53.7% |
| 同一候选 / 7 | 2000 | 11,124.82 | −20.46 | 4457.22 | 0.610 | 58.3% |
| 同一候选 / 123 | 2000 | 11,186.91 | +52.71 | 4569.33 | 0.655 | 54.6% |

相同seed42、相同2000回合预算下，候选利润较基线下降约0.067%，购电峰值反而升高约7.60%，日内标准差由840.39升至888.66 kW。其批发价相关性略提高，但原TOU相关性由0.752降至0.659，TOU时段均价排序也不稳定。**这些结果不支持把该候选称为全面优化，更不能替换基线成为推荐策略。** 2000回合的部分指标还不如500回合，延长预算不等于已经收敛。

候选seed42的充电/放电加权批发价分别为18.67/22.37澳分/kWh，较基线的19.32/20.36拉开了价差；但seed7仍有负储能边际收益。逐小时图中，候选在第5小时这个名义低价时段平均放电约606.78 kW，说明“整体买卖价差为正”远不足以证明每个时段都合理。多场景平均图同时出现充、放电曲线，是不同场景行为的平均；单个实际步没有同时充放电。

### 用户响应和电网购电分开判断

固定用原名义负荷最低/最高各6小时分类，并统一采用“实际减原基线”的符号。2000回合的结果为：

| 方案 / seed | 低负荷用户变化 kW | 高负荷用户变化 kW | 低负荷购电变化 kW | 高负荷购电变化 kW |
|---|---:|---:|---:|---:|
| 原基线 / 42 | +104.11 | −559.68 | +108.36 | −579.54 |
| 候选 / 42 | +344.41 | −684.07 | +370.35 | −779.51 |
| 候选 / 7 | +230.33 | −664.74 | +429.50 | −776.28 |
| 候选 / 123 | +220.14 | −541.12 | +528.01 | −926.21 |

候选seed42的低/高负荷用户变化分别约+14.80%/−15.49%，原基线为+4.47%/−12.67%。它们有平均填谷削峰的方向，但不能都称作“微调一点”。同时候选全天用电减少约10.96%，当前无回补模型中这主要包括需求抑制，不是已证实的等电量跨时转移。

同一风电实现下，原始负荷扣风电的平均购电峰值约4497.80 kW。候选seed42保持其实际价格/响应、仅在结算中移除储能时峰值约4144.66 kW，实际储能却把它增至4417.18 kW。这是同一响应路径的会计对照，不是重新优化过的无储能策略。它解释了为什么低/高负荷分组均值方向正确，仍可能在其他小时制造新峰；seed123的实际峰值甚至达到4569.33 kW。
