# 仅使用当前信息的6维状态：固定日500+1

本轮按用户指定范围，将纯SAC的状态从 `dispatch17` 简化为 `current6`：只保留当前批发价、当前原始负荷、当前风电、可用SOC比例、剩余时间和当前TOU。有效响应参考价、曲率、温度响应因子及所有未来批发价特征均不进入网络。实验协议仍为固定同一天训练500回合，随后只测试1回合；结果与图表由[本轮实验记录](../../experiments/sac_current6_500_20261018/README.md)汇总。本文先记录实现和协议，不预判简化后的收益或调度表现。

## 输入顺序和归一化

实现见 [`sac/task.py`](../../sac/task.py) 中的 `Task.__init__` 和 `Task.observe`。观测为 `float32`、形状 `(6,)`，顺序固定如下。小时 `h` 从0到23，`E` 表示当前储能量。

| 维度 | 含义 | 实际输入 |
|---|---|---|
| 1 | 当前批发电价 | `(grid_price[h] - 20) / 2` |
| 2 | 当前原始总负荷，响应前且未扣风电 | `baseline_load[h] / 5000` |
| 3 | 当前风电功率 | `wind_power[h] / 5000` |
| 4 | 可用SOC比例 | `(E - E_min) / (E_max - E_min)` |
| 5 | 剩余时域比例 | `(24 - h) / 24` |
| 6 | 当前原TOU计费参考价 | `2 * (TOU[h] - price_min) / (price_max - price_min) - 1` |

当前零售价边界仍为26.5–32.5，因此第6维也可写作 `2*(TOU[h]-26.5)/6-1`。SOC比例以物理下界到上界的可用容量为分母，不是储能量除以额定容量。最后一个决策时刻的剩余时间为 `1/24`，终止后的观测为6维零向量。

`20`、`2` 和 `5000` 是训练前冻结的数值尺度，不是运行时根据本日全日数据计算的均值、标准差或最大值。当前分支不使用整日批发价均值/标准差、整日最大负荷或依赖平均负荷的风电容量作为观测归一化系数。负荷与风电使用同一固定功率尺度；价格和功率归一化后不裁剪，超出常用范围的数值仍保留差异。

第6维是当前可知的原TOU信息，不是目标零售价，也不增加价格跟随规则。`current6` 不包含未来报价、未来报价极值及其时距、负荷预测、历史滞后量、正余弦时钟、末小时标志或储能可行动作上下界。

## 网络输入与环境模型的边界

当前实现仍是一个输出价格和储能两维动作的联合Gaussian Actor，以及两个标量Q Critic。Actor、回放缓冲区和两个Critic都使用同一组6维状态；每个Critic另接2维联合原始动作，合计8维状态动作输入。本轮没有拆成两个Actor，也没有改造EQN-SAC的不确定性集成结构。

逐时效用系数 `a,b`、曲率 `kappa=-a`、派生响应参考价和温度参与因子继续在环境内部按原公式计算。用户要求的是不把这些量提供给网络，并非删除需求响应模型。旧 `dispatch17` 本身也没有独立的曲率维度；本轮没有为新状态补入曲率或系数表。

储能可行上下界仍由SOC和设备参数计算，并用于原始储能动作到物理可行区间的映射；它们不作为额外观测。原价格动作边界、能量平衡、三次满意度/参与率迭代和利润结算均保留。训练奖励仍为 `0.001 * 原利润`，没有新增平滑、削峰、价格跟随奖励或约束；SAC自身的熵项也保持原设置。

环境为生成固定日、计算响应和结算而持有完整24小时数据，与将未来数据作为策略输入是两件事。`current6` 直接读取当前小时的价格、负荷、风电和TOU，并直接计算SOC比例，不从旧19维环境状态中截取未来预测字段。运行时记录的参考方案、响应参数和完整曲线用于审计，不进入这6维观测。

## 配置与500+1协议

本轮配置为 [`configs/sac/current6_500.json`](../../configs/sac/current6_500.json)。与[午间降价候选配置](../../configs/sac/midday_price_500.json)逐字段核对，配置文件唯一变化为 `observation: dispatch17 → current6`。逐时 `a,b`、响应与设备参数、原始曲线、随机种子和训练超参均相同；新的固定归一化方式由 `current6` 代码分支定义。

| 项目 | 本轮设置 |
|---|---|
| 环境数据 | 同一个固定24小时日；负荷、批发价使用原名义曲线，风电为固定功率 |
| 环境随机性 | 曲率、需求、参与三项噪声标准差均为0 |
| 种子 / 设备 | seed 42 / CPU单线程 |
| 训练预算 | 500回合，每回合24步，共12000环境步 |
| 内部策略评价 | `evaluation_every=0`，不进行训练前、中途或训练结束时的内部评价 |
| 最终测试 | 训练完成后仅对最终检查点执行一次 `evaluate --cases 1` |
| 学习设置 | 隐藏层128，batch 256，warmup 480步，每步更新8次，gamma 1 |
| 学习率 | Actor `5e-5`，Critic `5e-4`，alpha `3e-4` |
| 熵与目标更新 | 初始alpha `0.05`，目标熵 `-4`，target tau `0.01` |

环境无随机性不代表训练完全没有随机性：动作探索、网络初始化与回放抽样仍遵循固定种子的随机过程。最终对比只读取已经保存的单个24小时测试轨迹，不增加策略测试，不对动作或负荷做平滑，不平均多个案例。

## 复现与离线比较

以下命令从仓库根目录执行，使用新的输出目录，避免覆盖本轮原记录 `runs/sac_current6_500`。训练输出目录和测试输出文件必须尚不存在。命令展示一次完整复现所需的500回合训练和唯一1回合测试；本轮已有结果无需再次执行它们。

```bash
.venv/bin/python train_sac.py train \
  --config configs/sac/current6_500.json \
  --output runs/sac_current6_500_reproduce

.venv/bin/python train_sac.py evaluate \
  --checkpoint runs/sac_current6_500_reproduce/checkpoint_00500.pt \
  --cases 1 \
  --output runs/sac_current6_500_reproduce/test_1ep.json
```

训练目录会保存配置、有效环境、冻结源码及哈希manifest。以后若活动源码发生变化，应使用该次运行的冻结源码完成对应检查点的测试；检查点加载器会核对模型、观测、物理和数据来源。

有上一轮本地运行记录及本轮已保存测试后，可运行以下离线比较。该工具读取轨迹和训练日志，不加载Actor、不调用策略评价。前后 `a,b` 完全相同，因此不使用 `--hourly-utility` 参数。

```bash
.venv/bin/python tools/plot_sac_fixed_day_comparison.py \
  --before runs/sac_midday_price_500 \
  --after runs/sac_current6_500_reproduce \
  --output experiments/sac_current6_500_20261018/figures_reproduce
```

若只查看本轮正式记录，把 `--after` 换成 `runs/sac_current6_500`，并使用独立的图表输出目录即可。前后比较对象是相同固定环境中的两次完整训练，不需要重测上一轮模型。

## 如何解释比较结果

本轮同时改变了状态维度、特征内容和归一化方式。即使配置文件只改变一个字段，也不能把结果归因于某一个删项，或仅归因于从17维降到6维。输入维度改变还会改变网络首层形状与初始化过程；同为seed 42，不代表两次训练共享完全相同的初始权重或探索轨迹。

在同一个固定日、固定参数下，剩余时间可以识别时刻。策略通过500次重复可以学到日内日程，即使没有显式的未来报价输入。因此这轮可用于检验“只给当前6维信息是否足以学好这一个固定日”，不能据此宣称策略已经能够预测未见日期，或在随机负荷、风电、价格与不同效用参数下同样有效。单种子、单日、单回合测试也不能证明统计显著改善。

实际利润、定价、响应与储能购电曲线，以[本轮实验记录](../../experiments/sac_current6_500_20261018/README.md)及其保存的单次测试文件为准；本文不填入尚未确认的结果。
