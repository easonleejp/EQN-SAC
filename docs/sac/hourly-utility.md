# 按小时调整二次效用函数的 a、b

本轮已完成固定同一天的500回合训练和1回合最终测试，中午h11–15负荷加权削减率从18.6480%降至12.81995%。购电最大相邻小时变化减小，但峰值和差分RMS增大，因此不能称整条曲线更平滑。图表、逐小时数据与来源记录见[最新实验记录](../../experiments/sac_hourly_utility_500_20261018/README.md)。

用户明确允许二次效用函数的两个参数逐小时取不同值。本次使用`hourly_utility.a`、`hourly_utility.b`两个24小时数组，相对`fixed_day_refined_500.json`仅此配置字段改变；其他训练超参、17维状态结构、设备、输入数据、TOU、奖励和动作规则沿用前一轮。两轮都为固定无环境随机扰动的一天，训练500回合后只测试最终模型1回合，`evaluation_every=0`，无训练内部评价。SAC训练探索及回放抽样仍有随机性。

## 系数与原响应公式的关系

约定总量层效用为`U_t(L)=a_t*L²+b_t*L`，`a_t<0`。最大化`U_t(L)-p_t*L`得到理性需求`L*=(p_t-b_t)/(2*a_t)`。

原代码的等价参数为：

```text
curvature_t = -a_t
response_reference_t = b_t + 2*a_t*baseline_load_t
```

三类用户按已有负荷份额`s_i`使用`a_ti=a_t/s_i`、`b_ti=b_t`，继续执行原理性需求计算及三次满意度/参与率迭代。因此最终实际需求不等于纯二次效用的理性最优需求，不能省略参与率环节。

`response_reference`是效用参数推导出的响应零点，不是原始TOU。允许改变a、b后，它自然可以变化；原TOU、批发价、零售价上下限和账单参照没有改。曲率与参考价仅为两个系数的派生量，不是额外可调参数。

## 本次参数构造

沿用前一轮等效`a=-0.0011`及每小时原参考价，使用7–15时逐渐增强再减弱的调整，11时幅度最大：

```text
w_t = 0.5 * (1 + cos(pi*(t-11)/5))，当 |t-11| <= 5；其他时段为0
kappa_t = 0.0011 * (1 - 0.20*w_t)
reference_t = old_reference_t + 1.8*w_t
a_t = -kappa_t
b_t = reference_t + 2*kappa_t*nominal_baseline_load_t
```

这些表达式只用于一次性生成24对参数并保存到配置，不进入策略动作或奖励。首尾权重为0，所以0–6及16–23时的等效响应参数保持原值。不是对最终负荷曲线作平滑。

本次并非简单让曲线斜率变小：a、b共同变化，使中午响应零点上移，降低常见零售价附近的实际削减，同时保留价格决策的内部最优空间。不能把“当前价格下削减降低”说成“所有价格下弹性都降低”。

训练前按原响应公式进行静态检查：在旧策略价格下，10/11/12时削减约11.42%/11.60%/10.61%；每小时静态利润最优下约8.26%/8.73%/9.87%，对应价格31.700/32.100/32.365。这只是参数选择检查，不是SAC测试，不给网络提供价格标签或最优动作。

参数在训练前固定，记录见新实验的[`selection_before_training.json`](../../experiments/sac_hourly_utility_500_20261018/checks/selection_before_training.json)和[`parameter_proposal.json`](../../experiments/sac_hourly_utility_500_20261018/checks/parameter_proposal.json)。这些a、b是人工建模调参，构造的是合成响应情景，没有使用真实客户数据拟合。

## 实现与验证口径

配置入口为`configs/sac/hourly_utility_500.json`。只增加`hourly_utility`，其他字段与`fixed_day_refined_500.json`逐值相同。显式小时系数优先于原全局曲率均值；`hourly_utility={}`继续使用原路径。a、b都必须有24个有限实数，a为负且不被原曲率下限截断，曲率噪声标准差必须为0；b是效用系数，不按零售价范围裁剪。

运行时参考价用当前三类float32负荷之和计算，并由响应函数与状态共用，避免状态看到旧参考价。保存的名义参考表用原名义负荷计算；两者的浮点差异为`2*a*ΔB`，不改变数据或额外修正需求。未配置小时系数时不做a、b的来回换算，保留原数值顺序与随机调用。

逐时系数与原标量响应的等价性、默认路径及RNG一致性、状态不读未来随机实现值、奖励恒等式和参数校验均有测试。中午指标预先定义为h11–15（11:00–16:00），削减率按该窗口原始负荷加权：`sum(原负荷−实际用户负荷)/sum(原负荷)`。两轮都使用seed 42，各训练500回合、12000环境步和92168次梯度更新；各自保存的最终测试仅有1个24小时回合。

## 本次单回合结果

下表来自[`offline_comparison.json`](../../experiments/sac_hourly_utility_500_20261018/run/offline_comparison.json)，只读取两条已保存测试轨迹计算，没有重新运行策略。测试动作和负荷没有平滑或跨案例平均。

| 指标 | 上一轮refined | 本轮逐时a、b | 变化 |
|---|---:|---:|---:|
| h11–15加权削减率 | 18.6480% | 12.81995% | −5.8281个百分点 |
| h11削减率 | 21.7129% | 11.8402% | −9.8727个百分点 |
| h12削减率 | 20.1151% | 10.7681% | −9.3470个百分点 |
| 日利润（澳分，建模单位） | 1,150,657.31 | 1,171,937.33 | +1.85% |
| 购电峰值（kW） | 2,715.06 | 2,970.59 | +9.41% |
| 购电峰谷差（kW） | 912.21 | 1,031.63 | +13.09% |
| 购电标准差（kW） | 217.55 | 260.88 | +19.91% |
| 购电相邻小时差分RMS（kW） | 176.73 | 248.02 | +40.33% |
| 购电最大相邻小时变化（kW） | 516.42 | 449.39 | −12.98% |

差分RMS按24小时曲线的23个相邻差计算：`sqrt(mean((grid[h+1]−grid[h])²))`。最大差分下降而RMS上升，表示最大的单次跳变减小，但所有相邻变化的均方根增大；不能据最大跳变一项判断全日更平滑。中午削减减弱也没有带来更低的购电峰值。对照两轮，中午减小削减的目标达到了，购电波动和峰值存在上述代价。

价格仍呈总体TOU谷、平、峰均价递增；22→23时零售价变化由−0.03891变为−0.10396澳分/kWh，没有重新出现该处反向上调。这是一个固定日的结果，不代表所有小时严格单调，也不证明未知日泛化。需求响应仍不包含跨时能量补回机制，减小削减不能解释为将同等用电量转移到了其他小时。

利润增加1.85%同时包含效用系数改变和重新训练策略的影响。响应环境已经不同，不能当作同环境下算法优劣或真实客户收益改善的证据。单位沿用本轮澳分/kWh、kW、kWh的建模约定，原数据单位未被独立证实。上一轮[固定日改进说明](fixed-day-refinement.md)和配置仍保留，便于分别复现。
