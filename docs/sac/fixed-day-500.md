# 固定同一天：500回合训练、1回合测试

本次只完成一个固定日配置的500回合训练，最终检查点执行1个24小时测试回合。没有中途策略评价，没有再追加回合或多场景测试。训练日志、冻结源码和实际结果见[实验记录](../../experiments/sac_fixed_day_500_20261018/README.md)。

## 固定数据与调整范围

负荷和批发电价直接使用原始名义日，原TOU、响应参考价和价格边界不变。原数据没有名义风电轨迹，本次定义恒定风电为日均负荷的20%，约723.27 kW；这是确定性简化输入，不是复原出的实测风电。曲率、需求、参与三项噪声标准差全部设为0。训练每天与最终测试使用相同输入，SAC训练探索及回放抽样仍有随机性，最终测试采用确定性Actor动作。

原先参与率噪声的0.025是公式中的硬编码。本次只将该标准差暴露为参数，默认仍为0.025，固定日设为0；响应公式本身未更改。奖励仍为原利润乘0.001，没有增加削峰、平滑、价格跟随奖励或调度约束。原有SOC可行区间映射保持不变。

| 项目 | 本次配置 | 用意 |
|---|---|---|
| 响应曲率均值 | 0.0011，原值0.001 | 略降低响应强度，不改公式 |
| 状态 | `nominal11` | 去掉固定日冗余历史，提供当前信息与剩余名义价差 |
| Actor / Critic学习率 | 0.0001 / 0.001 | 减慢策略变化、加快价值拟合 |
| 初始温度 / 目标熵 | 0.1 / −3 | 降低训练后期动作探索强度 |
| 折扣 / 目标网络系数 | 1.0 / 0.01 | 保留完整24小时收益与跨时储能价值 |
| 预热 / 批量 / 每步更新 | 480 / 128 / 4 | 在500回合内增加样本复用，共46084次梯度更新 |
| 储能功率上限 | 967.77 kW | 名义负荷峰值的20% |
| 储能能量上下限 / 初始值 | 483.89–4354.97 / 483.89 kWh | 对应4838.85 kWh名义容量的10%–90%，从下限开始 |
| 两向效率 / 吞吐成本 | 0.95、0.95 / 0.5 | 原值保持；循环效率90.25% |

可用储能3871.08 kWh是功率上限的4倍；名义容量/功率为5小时，不能混称为4小时名义电池。设备规模与20%渗透率的文献背景见[参数审查](parameter-review-20261018.md)，本次没有新增文献适用性或真实用户校准的证据。

11维状态依次为当前批发价、原始负荷、风电、可用SOC比例、剩余时间、时间正弦/余弦、当前TOU、响应参考价、剩余时段名义批发价最大/最小值。未来名义价格来自已知模板，当前时刻以后的实际随机数组不参与观测。信息输入不决定必须执行哪一种动作。

## 单次结果与尚存问题

充电量加权批发价18.024，放电量加权批发价22.308；98.16%的充电量位于名义批发价最低四分位时段，79.78%的放电量位于最高四分位时段。主要充电在3–7时，主要放电在18–20时。初始/最终SOC为483.89/486.96 kWh，SOC和购电能量守恒、功率上下限及无同时充放电核验通过。

零售价与批发价Pearson相关系数0.863；按原TOU谷/平/峰分类的零售均价为28.444/31.873/32.462，整体顺序正确。但23时批发价从19.598降至19.507，零售价从30.276升至31.163；8–12时也明显高于原TOU，尚不能说逐小时都符合目标。

响应后用户负荷峰值从4838.85降至4301.67 kW（−11.10%），谷值从2067.46升至2445.74 kW（+18.30%），峰谷差下降33.03%，小时变化的RMS从307.11降至234.81 kW（−23.54%）。这说明峰谷和绝对波动改善，但18时附近仍保留晚高峰。日总用电减少13.25%，峰均比由1.338升至1.371，不能把全部改善称作移峰，也不能说所有平滑指标都变好。

储能把同一响应下的购电峰值从3578.40降至2702.38 kW，标准差从499.49降至236.94 kW；但小时变化RMS由234.81升至261.11 kW，3时充电开始、21时放电结束仍造成跳变。削峰成立不代表动作或购电逐小时已经足够平滑。

测试利润1148953.16原货币单位，原TOU且零储能参考策略1103034.89（+4.16%）；这是同环境下的参考策略，不是上轮训练策略。按暂定“澳分/kWh、kW、kWh”单位，测试利润为11489.53澳元，储能净贡献约46.38澳元。单位仍是建模约定，未恢复原数据来源。

训练后20回合平均原利润1146670.24，标准差1266.11，曲线趋稳；这只是训练收益观察，不构成全局收敛或跨日期泛化证明。当前500+1协议已完成，进一步调整应另存新运行，保留本次结果。
