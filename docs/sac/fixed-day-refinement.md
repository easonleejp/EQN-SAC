# 23时定价与储能跳变：第二次固定日500+1

本次按相同固定数据训练500回合、测试1回合，前后图及完整数字见[实验记录](../../experiments/sac_fixed_day_refined_500_20261018/README.md)。没有额外试跑、参数扫描或中途策略评价；原奖励和动作规则不变。

## 原问题与改动依据

前一次22时/23时零售价30.2757/31.1630，而批发价19.5980/19.5068下降。对零噪声原响应公式做离线静态价格扫描，两个小时的利润最优价约30.5171/30.2683。23时上调不是现有公式要求的方向。该小时定价损失只占全天利润约0.0301%，因此全天利润趋稳仍可能掩盖明显的局部错误。扫描没有加载Actor，也不参与训练或替换动作；它的数值精度与范围见本轮独立审查JSON。

前一次2→3时购电增加783.63 kW，储能从放7.85切为充810.99，贡献818.83 kW跳变，而响应后的净负荷下降35.20。20→21时购电增加431.13，其中放电骤减贡献554.61；21时仅剩15.47 kWh可用能量，已无法继续大量放电。前者涉及时段分配，后者涉及能量耗尽，不应仅按动作曲线形状下结论。

原11维已有时间信息，不是非Markov状态。新增末小时标志旨在减轻有限时域末步价值的拟合难度；可用功率和名义极值时距让网络更直接看到已有物理条件和价差机会。增加信息不保证自动产生平滑动作。

## 结果与取舍

22→23时价格从上涨0.887改为下降0.039；零售价与批发价相关系数从0.863升至0.922，按原TOU谷/平/峰分类的零售均价仍递增（28.753/31.521/32.466）。这不代表每个相邻小时都严格同向，也不代表价格精确等于原TOU。

最大购电跳变减少34.10%，购电变化RMS减少32.32%；储能功率最大跳变减少26.79%，变化RMS减少20.18%。大部分充电仍在低价时段，主要放电在17–20时，18–19时放电约861 kW。最终SOC485.16 kWh，仅比初始多1.28 kWh。夜间约1–3 kW的小幅充放交替仍存在，不能声称所有来回动作都消失。

降低额定功率并不必然延长充放时段；它首先限制可实现幅度，也会改变套利和削峰能力。本次购电峰值上升0.47%，储能净贡献下降10.73%；零售定价改进后总利润增加0.148%。单独的用户响应负荷变化RMS反而从234.81升到257.10 kW，谷值从2445.74降至2191.57 kW，填谷幅度减弱。用户负荷与电网购电应分开报告。

本次达到了指定两处问题的改进，但仍有台阶和其他取舍。训练预算按500回合完成，不追加训练去挑选更好看的结果；比较图使用真实逐小时数据，仅训练曲线叠加尾随均值。
