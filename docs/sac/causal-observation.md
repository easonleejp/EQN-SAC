# causal13：当前与历史信息的13维状态

当前SAC使用 [`configs/sac/causal13_500.json`](../../configs/sac/causal13_500.json)，唯一实验档案为[固定日500+1记录](../../experiments/sac_causal13_500_20261018/README.md)。旧SAC版本的文件已从当前工作树删除，Git历史仍可追溯；本文只说明保留版本，不依赖旧实验文件。

## 输入顺序与固定尺度

实现见 [`sac/task.py`](../../sac/task.py)。观测为形状 `(13,)` 的 `float32` 数组；`h` 为0–23小时，`c` 为实际批发价，`B` 为响应前总负荷，`W` 为风电，`E` 为当前储能量。

| 维度 | 含义 | 输入定义 |
|---|---|---|
| 1 | 当前批发价 | `(c[h]-20)/2` |
| 2 | 当前原始总负荷 | `B[h]/5000` |
| 3 | 当前风电功率 | `W[h]/5000` |
| 4 | 可用SOC比例 | `(E-E_min)/(E_max-E_min)` |
| 5 | 剩余时间 | `(24-h)/24` |
| 6 | 当前原TOU | `2*(TOU[h]-price_min)/(price_max-price_min)-1` |
| 7 | 日内正弦时钟 | `sin(2*pi*h/24)` |
| 8 | 日内余弦时钟 | `cos(2*pi*h/24)` |
| 9 | 前1小时批发价 | `(c[max(0,h-1)]-20)/2` |
| 10 | 前2小时批发价 | `(c[max(0,h-2)]-20)/2` |
| 11 | 前3小时批发价 | `(c[max(0,h-3)]-20)/2` |
| 12 | 当前物理归一化放电下界 | 原 `feasible_bounds()` 返回的 `lo` |
| 13 | 当前物理归一化充电上界 | 原 `feasible_bounds()` 返回的 `hi` |

零售价边界为26.5–32.5。价格中心20、尺度2和功率尺度5000均为预先固定常数，不根据全日均值、标准差、极值或未来数据估计；归一化后的价格、功率不裁剪。终止时返回13维零向量。

按lag1、lag2、lag3排列，日初历史为：h0 `[c0,c0,c0]`，h1 `[c0,c0,c0]`，h2 `[c1,c0,c0]`，h3 `[c2,c1,c0]`。不足部分重复第0小时已观测价格，不跨日环绕取h23，不用未来名义报价填充。

## 物理含义与信息边界

上下界由当前SOC、功率限值和效率决定，是原物理约束的观测。原始储能动作 `u` 按 `v=lo+(u+1)*(hi-lo)/2` 映射为实际归一化动作。例如SOC在下界时，区间为 `[0,1]`，原始动作0对应半功率充电。提供边界帮助网络识别随SOC变化的动作含义，没有修改映射或增加约束。

状态不包含未来报价、未来极值及其时距、预测曲线、全日统计量、有效响应参考价、曲率、温度响应因子或过去实际功率。逐时a、b、温度和参考价仍在环境内部按原响应公式使用。时钟只计算当前时刻，历史索引不超过当前小时。

正余弦提供平滑的日内位置编码；剩余时间保留日末与日初的区别。环境没有跨日接续价值或末端储能残值，不能只用循环时钟代替有限时域信息。历史价格描述过去涨跌，不提供晚峰价格保证。

在固定曲线、固定参数条件下，时间与SOC已经标识环境状态，时钟和历史报价是时间的函数，边界是SOC的函数。这些特征用于改善函数表达，不是补充固定日缺失的Markov信息；既不保证任何新训练都能为晚峰留电，也不证明随机场景满足Markov条件。

## 固定日500+1协议

一个联合Actor和两个标量Critic使用相同13维状态；每个Critic另接2维联合原始动作。奖励为 `0.001×原利润`，没有新增价格跟随、削峰或平滑要求。响应方程、逐时效用参数、设备和动作规则以当前配置及有效环境快照为准。

训练使用seed 42、CPU单线程、预热1200步、隐藏层128、batch 256，每步更新8次。Actor、Critic、alpha学习率分别为 `2e-5`、`5e-4`、`3e-4`；初始alpha `0.05`，目标熵−2，gamma 1，target tau `0.01`。目标熵是二维动作的启发式，不由13维观测决定。

同一个24小时日的负荷、批发价和恒定风电重复使用，三项环境噪声为0，训练探索与回放仍有随机性。实际预算为500回合、12000步、86408次更新；`evaluation_every=0`，无内部评价。最终检查点只测试1回合、24步，当前结果见[单次测试文件](../../experiments/sac_causal13_500_20261018/run/test_1ep.json)。

## 独立复现与当前图表

查看现有档案无需重新运行模型。本次文件整理也没有重新训练或评价。需要独立复现时，从仓库根目录使用当前冻结源码和全新输出目录：

```sh
python experiments/sac_causal13_500_20261018/run/source/train_sac.py train \
  --config configs/sac/causal13_500.json \
  --output runs/sac_causal13_500_reproduce

python runs/sac_causal13_500_reproduce/source/train_sac.py evaluate \
  --checkpoint runs/sac_causal13_500_reproduce/checkpoint_00500.pt \
  --output runs/sac_causal13_500_reproduce/test_1ep.json \
  --cases 1 --seed 20260914
```

```sh
python tools/plot_sac_fixed_day.py \
```
