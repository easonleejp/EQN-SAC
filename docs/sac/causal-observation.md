# causal13：当前与历史信息的固定日状态扩展

本轮在[调参后的current6](current6-training.md)基础上，追加时钟编码、过去批发价和当前储能可行动作上下界，形成 `causal13`。配置为 [`configs/sac/causal13_500.json`](../../configs/sac/causal13_500.json)，正式运行目录为 `runs/sac_causal13_500`。结果另见[实验记录](../../experiments/sac_causal13_500_20261018/README.md)；本文说明实现与协议，实际表现以保存的单次测试为准。

## 13维输入及固定尺度

实现见 [`sac/task.py`](../../sac/task.py)。观测为形状 `(13,)` 的 `float32` 数组；`h` 为0–23小时，`c` 为实际批发价，`B` 为响应前总负荷，`W` 为风电，`E` 为当前储能量。前6维与current6逐项相同。

| 维度 | 含义 | 输入定义 |
|---|---|---|
| 1 | 当前批发价 | `(c[h]-20)/2` |
| 2 | 当前原始总负荷 | `B[h]/5000` |
| 3 | 当前风电功率 | `W[h]/5000` |
| 4 | 可用SOC比例 | `(E-E_min)/(E_max-E_min)` |
| 5 | 剩余时间 | `(24-h)/24` |
| 6 | 当前原TOU | `2*(TOU[h]-price_min)/(price_max-price_min)-1` |
| 7 | 日内正弦时钟 | `sin(2*pi*h/24)` |
| 8 | 日内余弦时钟 | `cos(2*pi*h/24)` |
| 9 | 前1小时批发价 | `(c[max(0,h-1)]-20)/2` |
| 10 | 前2小时批发价 | `(c[max(0,h-2)]-20)/2` |
| 11 | 前3小时批发价 | `(c[max(0,h-3)]-20)/2` |
| 12 | 当前物理归一化放电下界 | `lo`，由原 `feasible_bounds()` 返回 |
| 13 | 当前物理归一化充电上界 | `hi`，由原 `feasible_bounds()` 返回 |

零售价边界仍为26.5–32.5。价格中心20、尺度2及功率尺度5000均为预先固定常数，不从本日全日均值、标准差、极值或未来数据估计；价格和功率归一化后不裁剪。终止时返回13维零向量。

日初缺失历史用第0小时已观测价格填充：h0为 `[c0,c0,c0]`，h1为 `[c0,c0,c0]`，h2为 `[c1,c0,c0]`，h3才是完整的 `[c2,c1,c0]`。这里按lag1、lag2、lag3排列，绝不跨日环绕读取h23，也不用未来名义报价填充。

## 当前物理信息与未来信息的边界

上下界来自当前SOC、功率限值和效率，是原有物理可行区间，不是新增约束。原始储能动作 `u` 仍按 `v=lo+(u+1)*(hi-lo)/2` 映射为实际归一化动作。例如SOC处于下界时，区间为 `[0,1]`，原始动作0对应半功率充电；提供上下界是为了让网络更容易识别这种随SOC变化的动作含义，映射本身没有改变。

本轮不输入未来报价、未来极值或时距、预测曲线、全日统计量、有效响应参考价、曲率、温度响应因子或过去实际功率。逐时a、b、温度和参考价继续在环境内部按原响应公式使用。正余弦只计算当前时刻，历史报价索引均不超过当前小时，不隐含未来实现。

正余弦提供平滑的日内位置编码，原剩余时间仍保留，以区分日末和日初。当前环境没有跨日接续价值或末端储能残值，不能只用循环时钟代替有限时域信息。过去价格描述已发生的涨跌，不能告诉策略晚峰价格一定更高。

在本轮固定曲线、固定参数条件下，current6已经通过时间和SOC标识状态。新增时钟和历史价格是时间的函数，上下界是SOC的函数；这属于函数表达上的改进尝试，不是补充固定日缺失的Markov信息。它可能降低有限训练的拟合难度，但不保证策略为晚峰留电，也不能据此声称随机场景已满足Markov条件。

## 相同超参的500+1协议

配置与 `current6_tuned_500.json` 的唯一字段差异是 `observation: current6 → causal13`。预热1200步、Actor学习率 `2e-5`、Critic学习率 `5e-4`、alpha学习率 `3e-4`、初始alpha `0.05`、目标熵−2、隐藏层128、batch 256、每步更新8次、gamma 1及target tau `0.01`均保持不变。目标熵依据两维动作设置，不随13维观测改变。

架构仍为联合Actor与两个标量Critic，均使用13维状态；每个Critic另接2维联合原始动作。逐时效用参数、设备、动作规则和 `0.001×原利润` 奖励不变，没有增加价格跟随、削峰或平滑要求。

固定seed 42、同一个24小时日，三项环境噪声为0；训练探索和回放抽样仍有随机性。训练预算为500回合、12000步，按现有更新门槛为86408次更新。`evaluation_every=0`，不做内部评价；完成后只对最终检查点测试1回合、24步。离线比较只读取保存轨迹，不额外调用策略，不平滑测试动作或负荷。

## 复现与离线比较

从仓库根目录执行，使用尚不存在的输出目录。以下示例是一轮完整复现，已有本轮结果无需再次训练或测试；测试使用该次训练冻结的源码。

```bash
.venv/bin/python train_sac.py train \
  --config configs/sac/causal13_500.json \
  --output runs/sac_causal13_500_reproduce

.venv/bin/python runs/sac_causal13_500_reproduce/source/train_sac.py evaluate \
  --checkpoint runs/sac_causal13_500_reproduce/checkpoint_00500.pt \
  --output runs/sac_causal13_500_reproduce/test_1ep.json \
  --cases 1 --seed 20260914

.venv/bin/python tools/plot_sac_fixed_day_comparison.py \
  --before experiments/sac_current6_tuned_500_20261018/run \
  --after runs/sac_causal13_500_reproduce \
  --output checks/causal13_reproduce_figures
```

前后a、b不变，比较命令不使用 `--hourly-utility`。本轮一次增加7维，结果不能分离时钟、历史价和物理边界各自的贡献；输入形状改变也会影响初始化。单seed固定日结果不证明未知日期泛化，实际结论须以保存的唯一测试为准。
