# 本地历史归档

`local/` 完整保留整理前的原交接包、两轮代码审查和原根 README。目录整体迁移，原文件内容保持不变；其中的代码副本均为历史记录。当前开发请只使用仓库根目录的 `train.py` 与 `eqnsac/`。

| 本地路径 | 内容 |
|---|---|
| `local/EQN-SAC_项目交接_20261018/` | 原交接包：稿件、导师意见、原始数据、参考论文、三组完整实验、历史来源代码 |
| `local/代码审查_20261018/` | 第一轮审查、修改前代码、验证产物与历史模型复查 |
| `local/算法与可读性审查_20261018/` | 原论文对照、可读性重构、修改前代码和行为等价验证 |
| `local/README_before_reorganization.md` | 整理前项目导航 |

[inventory.json](inventory.json) 记录702个原始文件的新旧路径、字节数和 SHA256，系统缓存不计入。清单用于核验归档内容；整理后新增开发文档和验证输出不属于这份原始清单。

`local/` 不加入 Git，避免把虚拟环境、论文附件、原始150MB CSV和约240MB模型混入日常开发提交。本地文件没有删除。线上仓库保留运行必需的3个训练JSON；历史实验的冻结源码、日志和评价另存于 `experiments/`。

原文档内的历史绝对路径和审查证据原样保留；这类路径表示来源，不是当前运行依赖。早期审查验证脚本也是历史证据，可能依赖整理前布局。日常检查使用根目录 `tests/` 和 `tools/`。

从远端克隆后不会自动获得 `local/`。如需重评最终模型，将对应检查点从本机归档复制到同组 `experiments/historical/<实验名>/run/checkpoint.pt`，并核对清单哈希；模型文件仍由 `.gitignore` 排除。
