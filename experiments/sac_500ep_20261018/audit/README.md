# 审查证据

这些文件从本机 `checks/sac_audit/` 复制，哈希见 `source_manifest.json`。论文全文、出版商图片和模型权重没有包含在此目录。

- `code_review.json`：本轮纯 SAC 核心和五组试验的最终代码审查；回放恢复的 P2 校验问题已修复。
- `final_tests.log`：开发代码的 68 项测试通过记录。冻结训练源码保留运行当时版本，不用训练后的校验修复覆盖。
- `env/`：共享业务环境的独立诊断、参考策略权重标定和价格扫描。线性规划含完美未来信息，是诊断比较，不是可部署策略，也不是 SAC 的成绩。
- `literature/`：期刊出版元数据、公式位置与模型差异。该文献记录开始于新 SAC 代码建立之前，`scope` 和 Git HEAD 保留当时原文；其环境结论适用于未改变的共享环境，不能将其中原 EQN Agent 的快照当作新 SAC 实现。完整的当前结论见[最终审核报告](../../../docs/sac/review-20261018.md)。

诊断脚本保留采集时路径，执行前应从仓库根目录阅读其输出目录；原始证据文件本身没有重新生成或改写。审查 JSON 中的行号对应采集版本。
